证据定位

核定位、互作和结构相似分别回答“是否可能进入核内”“是否连接已知调控网络”“是否存在表观结构域样折叠”三个不同问题。

解释尺度

结构命中按折叠层面的相似性理解，不能直接等同于新结构域注释或已确认调控功能。

复核重点

优先检查命中区间的 AlphaFold 置信度、结构叠合质量、同类弱注释和互作来源可靠性。

方法流程

从全蛋白质组扫描到候选复核的分析链

流程以标准化蛋白组和调控锚点集合为起点，通过三条相互独立的证据线逐级收缩候选空间，并在最终交集处保留可追溯的候选解释。

01

背景蛋白组与调控锚点定义

建立 20,416 个人类已审阅标准蛋白的背景集合；整理 1,613 个 TF 锚点与 794 个 EpiFactors 锚点，形成 PPI 分析的内部调控锚点口径。

02

直接核定位候选筛选

从无明确 UniProt Nucleus 注释的 14,674 个蛋白出发，使用 DeepLoc ProtT5 与 NLSExplorer 进行全量推理；双模型阈值均大于 0.5 时保留，得到 1,215 个候选。

03

调控锚点互作证据整合

整合 HI-union 实验互作与 RF2-PPI final80 高置信预测互作，提取非 TF / 非 EpiFactor、但连接已知调控锚点的外部互作蛋白；与核定位候选交叉后得到 382 个中间候选。

04

经典表观结构域相似搜索

构建 6 类经典表观调控结构域、共 48 个裁剪后的结构域级查询 PDB，对 23,317 个人类 AlphaFold DB v6 结构进行 Foldseek 搜索，并按 qTM 与覆盖度过滤。

05

三证据交集与候选分层

将 382 个核定位 + 互作候选与 143 个 Foldseek 基础候选按 UniProt 编号精确取交集，得到 7 个蛋白；进一步用同类结构域注释区分注释外结构命中与已有注释复核对象。

证据模型

三条独立证据线的定义、阈值与适用范围

本轮不依赖单一模型分数排序，而是要求候选同时获得定位、互作和结构三个层面的支持。每条证据线均保留明确的输入集合、阈值口径和反向解释限制。

证据线 A

直接核定位倾向

输入为 UniProt 未明确标注细胞核定位的 14,674 个蛋白。DeepLoc 核定位概率与 NLSExplorer 蛋白层面最高概率均大于 0.5 时，视为直接核定位候选。

  • DeepLoc > 0.5：2,016 个蛋白
  • NLSExplorer > 0.5：3,701 个蛋白
  • 双模型交集：1,215 个蛋白

该证据识别直接核定位倾向，不用于排除通过信号通路间接影响核内过程的蛋白。

证据线 B

调控锚点互作连接

以 1,613 个 TF 锚点和 794 个 EpiFactors 锚点为内部调控网络，整合 HI-union 实验互作与 RF2-PPI final80 高置信预测互作，寻找外部新互作蛋白。

  • HI-union 外部互作蛋白：3,521 个
  • RF2 final80 外部互作蛋白：1,930 个
  • 合并外部互作蛋白：4,799 个

候选优先级需要区分实验互作与预测互作，并排查高频互作蛋白和技术噪声。

证据线 C

表观结构域样折叠

使用 6 类经典表观调控结构域的 48 个结构域级查询结构，与人类 AlphaFold DB v6 结构库做 Foldseek 搜索，保留按查询长度归一化的 qTM 与查询覆盖度达标的命中。

  • 基础候选：183 条命中 / 143 个蛋白
  • 严格候选：147 条命中
  • 三证据交集：9 条命中 / 7 个蛋白

结构相似是功能假说来源，需要结合局部 pLDDT、叠合质量和已有弱注释进一步复核。

候选分层

第一轮 7 个候选蛋白

候选按结构解释状态分层：注释外结构命中用于寻找潜在新结构线索；已有同类注释对象更适合作为流程回收、弱注释复核或生物学关联补充。

候选蛋白 证据判断
ALG13 探索候选（可能假阳性） ER 相关 N-糖基化通路

UniProt / GeneCards 主要将其注释为 ER 相关 N-糖基化通路的 UDP-GlcNAc 转移酶亚基，不属于典型核内染色质或转录调控蛋白；但三条证据链将它指向了调控蛋白，需实验审查

C11orf16 探索主候选 未表征蛋白 / DUF4537

UniProt 仍基本标注为未表征蛋白，仅见低复杂度、无序区和 DUF4537 等弱注释；具有较高未知蛋白挖掘价值，但需要依赖本项目的核定位、调控锚点互作和结构相似证据支撑。

FBXO21 探索候选 F-box / 泛素连接酶相关

GeneCards / UniProt 主要指向 F-box 与泛素连接酶相关功能，GO 注释包含 ubiquitin-protein transferase activity，不是经典 chromatin regulator。

PHF21B 表观 reader（有文献证据） PHD finger proteins

GeneCards 显示其属于 PHD finger proteins；已有研究将 PHF21B 描述为 epigenetic reader，并报道其影响转录组和神经相关表型。该候选适合作为功能未充分解析的表观 reader 候选，而非完全新蛋白。

PHF3 阳性对照（有文献证据） PHD zinc finger / SPOC

UniProt 标注 PHD-type zinc finger 与 TFIIS central domain；文献已显示 PHF3 可通过 SPOC domain 读取 RNA polymerase II CTD 磷酸化状态并调控转录和基因表达，更适合作为阳性或半阳性对照。

SMYD5 阳性回收（有文献证据） SET / 甲基转移相关

Nature Communications 等研究已报道 SMYD5 可被 RNA polymerase II 招募到染色质，并在启动子区域催化 H3K36me3；UniProt 也注释其 RPL40 K22me3 核糖体甲基转移酶功能，已知度较高，适合作为模型回收阳性对照。

ZCWPW2 表观 reader（有文献证据） PWWP / dual histone mark reader

UniProt 标注其可结合 H3K4me0/1/2/3；近期 Nucleic Acids Research 研究称其为 dual histone mark reader，并参与减数分裂重组以及乳酰化/转录调控相关过程。该候选不适合作为新颖性主打，但适合作为 reader 类阳性候选。

验证设计

结构与互作复查后，下一步应转向可验证的细胞实验

既然结构命中和互作证据已经完成初步复查，后续不需要继续重复筛表，而应把候选收敛为实验问题：候选是否稳定进入核内，是否能复现实验互作，扰动后是否改变转录或染色质读出。

一

候选收敛

将 C11orf16 作为探索主候选；ZCWPW2、PHF21B、PHF3、SMYD5 作为 reader 或阳性回收参照；ALG13 和 FBXO21 暂列为低优先级或条件性复核对象。

二

核定位确认

优先对 C11orf16 做标签表达或抗体免疫荧光，并配合核质分离 Western blot，确认其是否稳定进入细胞核或染色质组分。

三

定向互作验证

围绕已复查过的调控锚点设计 Co-IP、反向 Co-IP 或 BioID/AP-MS，不再做泛化互作筛查，而是验证 C11orf16 与具体 TF / EpiFactors 锚点是否可复现。

四

功能读出

在定位和互作成立后，再做 siRNA、CRISPRi 或过表达扰动，并用 RNA-seq、ATAC-seq、CUT&RUN / CUT&Tag 检查转录变化和染色质标记变化。
